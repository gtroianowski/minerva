# Graveyard

Historical material, excluded from active skill installation and normative guidance. Preserve it for provenance; do not load it as current instructions.

- `skills/engineer/`: early predecessor of Gerald, despite its name.
- `skills/clerk/`: second attempt at recordkeeping, superseded by Gerald; it also tried to own knowledge-system work.
- `bootstrapping/`: shelved automated-ingestion philosophy. Context-free knowledge accretion proved too ill-specified. The current direction is semi-directed accumulation guided by the user’s project objectives and reactions.

Residual proposals are indexed in [RFCs under review](../rfc/under-review/README.md). Archival copies retain their original text, including obsolete status statements and instructions. The bootstrap README also discusses the exploratory architecture skills that remain in `musings/skills`; their status is unresolved, not automatically shelved with this design.
